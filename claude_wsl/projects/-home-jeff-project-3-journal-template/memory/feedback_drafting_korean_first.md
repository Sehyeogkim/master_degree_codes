When drafting paper sections (Method, Result, Intro, etc.) in the paperflow project, write the
**Korean draft first in `4_contents/<section>.md`, then overwrite that file in place with the English
translation** once the Korean is confirmed. Do NOT keep Korean and English side-by-side; English is the
final artifact.

**Why:** Target journals are English; the Korean draft is a thinking/scaffolding step. User chose
"한글 먼저 → 영어로 교체" over coexisting bilingual files (2026-05-29).
**How to apply:** During step 4–6 drafting skills (`/draft-method-result`, `/draft-intro-discussion`,
`/abstract-title`). Translate preserving technical nuance, keep terminology consistent with `writing_style/`.
